# 新章节模板

将本目录的表格复制到目标章节，填写后再实施。目录中的“待填写”不是实验结果。后续按需要建立 src、scripts、public/experiments、research/upstream、research/experiments、checkpoints、manim、supplements；不要创建空壳代码或复制第一章数据当作新结果。

## 任务单

- 章节 / 状态 / 当前版本：
- 观众能理解的具体任务：
- 输入是什么、输出怎样验证：
- 先决概念与最少背景：
- 一个贯穿的例子、一个失败案例：
- 原论文、上游仓库 commit、许可：
- 实验配置、数据划分、种子、评估方案：
- 真实实验与原理示意的边界：
- 口播目标时长、视觉重点、版本依赖：
- 本次生成预算及任务台账路径（无授权则不调用）：
- 1080p 预览与确认记录：
- 4K 状态（待确认 / 已授权 / 已完成）：

## 发布检查

- [ ] 数据和失败样本可追溯，运行未覆盖旧记录
- [ ] 旁白、字幕、动作与测量时间一致
- [ ] 图形持续运动但不频繁闪动，数值保持对象身份
- [ ] 图表/代码/论文/Logo/来源与字幕无重叠
- [ ] 英文整体发音、多音字、尾音和降噪实际复听
- [ ] 全片解码、接缝观看、论文聚焦和响度检查
- [ ] assets 清单、来源、当前版本、README 更新
- [ ] 私密信息检查及第三方权利记录

检查结果注明自动/人工、执行时间、版本和未检查项，不自动勾选。
