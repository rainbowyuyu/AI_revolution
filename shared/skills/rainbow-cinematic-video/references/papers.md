# 真实论文、景深聚焦与自然退场

## 证据层

先区分用途：**预告／系列总览尾声默认一幅文献汇总场景**，不再逐篇轮读；**正式课讲机制时按需要展示单篇原文和相关图**。旧版逐篇 6–8 秒的例子只在选择单篇模式时适用。

用真实论文 PDF 的真实页面。侧边只保留短技术名、论文标题、作者、会议／期刊、年份；不显示长摘要、引用位置、URL 列表或密集解释。详细引用位置和文字核对保存在资料里。

论文下载后验证文件是 PDF、页数和版本正确。页码指 PDF 物理页序，从 1 开始，可能与印刷页码不同。用 PyMuPDF 文本搜索定位实际图、公式或段落；目视核实截图，不能只相信 OCR 或坐标。

每篇记录 `id, title, authors, venue, year, url, pdfUrl, page, pageWidth, pageHeight, focus:[x0,y0,x1,y1], verifiedText, sha256, image`。坐标为 PDF 点单位，不是截图像素。缩放 3 倍渲染会增加像素，不改变这些点坐标。旋转页必须显式处理坐标，不能套用未旋转矩形。

随附工具只处理本地 PDF，不访问网络、不生成内容：

```powershell
python <skill>/scripts/pdf_focus.py --pdf <paper.pdf> --page 5 --rect 102 75 509 272 --verify-text 'Figure 2: An illustration' --scale 3 --out-dir <project>/research/focus/alexnet
```

输出：未改动的整页 `page.png`、目标区域 `focus.png`、只用于核对的红框图 `locator-review.png`、`focus.json`。成片用 `page.png`；定位检查图不进正片。若验证失败停止该页准备，先修复来源或坐标。依赖 `PyMuPDF`；不自动修改现有 Python 环境。

## 页面视觉

页面是空间中的单张真实纸面，不做书、装订、翻页书脊、虚假纸张卷曲。初始稍倾斜且完整可辨，摄影机自然推近目标区域，周围正文随焦平面柔和失焦。白纸保留真实对比，少量暖／青色光照即可，不给论文套强烈金色滤镜。

参考布局：论文区域 x≈78、y≈162、1050×780；右侧元数据 x≈1160、宽≈610；标题 y≈92。不同论文图宽高比不同，逐篇调整，确保目标完整进入清晰区。长标题自然换行，作者不必全列；`第一作者 等` 与年份通常足够。

整页起始比例可用 `640 / pageHeight`；聚焦目标比例 `min(810 / focusWidth, 510 / focusHeight)`。相机中心从页中心移动到目标矩形中心，scale 与 center 共享平滑进度，避免先放大再跳位置。用实际图大小决定最大比例，不把页边缘裁断成硬边窗口。

## 焦平面实现

背景层放整页 PDF 并轻微模糊，上层放同一页的清晰副本，用两个渐变 mask 的交集形成羽化清晰区域。让羽化超过目标边界约 20–30 PDF 点，确保正文／图表本身清楚，不切成四块硬边模糊区。不再画聚焦角标。

缩放时羽化和模糊量也会放大，需按输出尺度审查。完整图表及必要图注保持清晰；页面其余部分适度虚化，让观众知道这是原论文而非重新绘制的假页。

## 推进、停留与交接

每篇约 6–8 秒是预告参考，详细解读需要更久。V10 以 30 fps、190 帧步长为例（local 为每篇基准帧偏移）：

| 动作 | 参考 local 帧 | 行为 |
|---|---|---|
| 入场 | −8 → 30 | 小幅位移与淡入，少量失焦收定 |
| 推向图表 | 22 → 112 | 平缓推近，Y 旋转约 −9° → −1.4° |
| 清晰停留 | 112 → 154 | 约 1.4 秒，保留必要微动而不晃动图表 |
| 后退／渐隐 | 151 → 202 / 154 → 196 | 沿光轴轻退，透明度平滑下降 |
| 延迟失焦 | 178 → 202 | 仅低透明度时增加约 2 px 模糊 |

相邻页微弱重叠，不在高不透明度时双页堆叠。移除背景中硬切换的“下一张论文”残影。元数据与页面协调退出，不能长时间显示前一篇作者配下一篇图。

最终收尾同步减弱论文、文字和环境光，保持同一背景；不要把整个容器淡出后露出下层旧片名或粒子球。渐变收束不等于必须黑屏。检查所有中间帧与正常速度节奏，不能仅凭终点截图验收。

## 总览文献汇总模式

选用确实相关的原论文 PDF 页，以前／中／后三层错落叠放，轻微 3D 旋转、距离差和景深形成空间。前景保留 1–2 张主要页面清晰可认，背景纸页柔和失焦；不把所有白页铺满画面。整组缓慢推进、展开或回收，不做书脊、翻书或不断快速换页。

旁边是克制的短列表：简称／标题、第一作者等、年份即可。列表字号可小于教学主文，但在实际 1080p 仍可读；完整书目放随片文档，不能要求观众读完十几段引用。不要显示长摘要、逐项引用位置或 URL。论文内容不能由图像生成模型伪造；生成只可用于环境或纸面之外的概念构图。

页面与元数据共用进退场节奏，清晰区跟随同一相机变换。淡出先平缓退景再降低透明度，低透明度时才加少量失焦；保持底层同一环境，避免上一场景的标题被突然露出。
