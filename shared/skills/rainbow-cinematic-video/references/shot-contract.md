# 逐句音画契约与路由

用于长篇教学、旁白更新、音画错位修复。核心不是“字幕贴着声音”，而是说到一个对象／动作时，画面确实展示它。字幕同步不证明教学内容同步。

## 单一时间基准

正式语音先测时长，再把每个语义短句映射到 `[from,to)`。统一维护镜头 ID、旁白 ID、字幕、数据样本 ID、阶段和素材。可用 JSON 或现有时间线，不强制迁移工程。

每句至少记录：

| 字段 | 用途 |
|---|---|
| narration/displayText/spokenText | 原始口播、字幕和实际送给 TTS 的文本可分别保存 |
| from/to、局部阶段锚点 | 以正式音轨定时，区分全片帧与组件局部帧 |
| goal/action | 这句话要观众看懂什么；画面具体做什么 |
| dataRef/sourceRef | 图片、概率、响应、状态、论文的可追溯文件及记录 ID |
| hold/transition | 阅读停留区间、插值区间、入出锚点 |
| caption/source/logo boxes | 最大文字占位与运动主体范围 |
| checked | 静帧、连续播放、实际复听分别记录，未做不写通过 |

若既有组件依赖旧音轨，建立单调的旧帧→新帧锚点映射；关键视觉阶段直接依照新旁白锚点更清楚。不能仅用 `local/duration` 均分阶段，也不能只替换 WAV 而沿用旧动画切点。

## 内容路由防错

- 使用稳定的语义场景 ID（例如 `classification-intro`、`experiment-overview`、`pixels-rgb`），不要把所有引入都叫 `overview`。
- 检查最先命中的渲染分支；共享组件的早返回可能覆盖后面的专用场景。审查实际渲染结果，不只查配置标题。
- 若一个版本的局部修复适合专用组件，限定到该版本和语义场景，不修改全局 overview 导致其他章节变样。既有索引分支至少注明映射并核对标题和帧区间。
- 纯视觉修复优先保留已正确音轨；若口播本身缺乏具体目标才改写并重对齐。

## 分类引言的真实故障与修复范式

第一章 V9 约 1:06–1:23 原旁白在讲新图片分类，共享 `Tasks` 却仍展示分类、平衡杆和棋盘。最终新增专用分类引言。以下是语义顺序，不是后续影片固定秒数：

| 听到什么 | 应该看到什么 |
|---|---|
| 输入一张没见过的图片 | 本次真实测试图片稳定入场，标明未参与训练 |
| 输出类别 | 从图片经过网络表示到类别输出；预测来自该图片的保存结果 |
| 数据有十类，猫狗只是两类 | 十类标签出现，猫狗强调但不改成二分类概率 |
| 找到新照片里的线索 | 切换真实另一张图片，特征与概率对应改变；数值平滑伸缩 |
| 不是背下某一张猫 | 展示任务意图；不以两张样本宣称已证明泛化 |
| 程序究竟收到什么 | 回到下一节同一张猫图，显露像素网格，接 RGB 输入 |

## 字幕的实际占位

优先按语义短句分段，保证正常阅读速度，不机械每 N 字断开。专名整体保留。字幕较长时优先重分时间段；确需两行，必须预留两行的真实高度，向上移动字幕不应覆盖来源、图表或代码。

在每个字幕段预先计算行数和布局，稳定到该段结束，避免逐帧换行造成跳动。长中文、英文、百分比和数学符号都用实际字体测量；不能只看字符数。SVG viewBox 缩放后字号按最终 1080p 像素检查。

渲染最长字幕、两行字幕、字幕切换、来源长标题和图表运动到边界的最坏帧。布局不足先缩短信息／改排版，不把所有文字缩成小字。

## 分层与接缝

背景、环境桥接、教学主体、标题、品牌、来源、字幕有明确层级。背景溶解不要包住整个前景造成讲话时内容被遮住。淡出上一场景只留下计划保留的共同物体，不透出旧标题或重复内容。

一处接缝至少比较：末句对应动作、出镜物体、首句对应动作、入镜物体、字幕区间、声轨尾部。接缝前后各约 0.5 秒检查，再正常速度播放整段。意图、对象和运动连贯比“每段都加一种转场”重要。
