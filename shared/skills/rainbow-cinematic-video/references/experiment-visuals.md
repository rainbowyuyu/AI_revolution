# 真实实验怎样成为教学动画

用于正式课程的机制、代码与实验结果。渲染读取固定数据，不在 React 渲染时训练或重新随机求解。保留仓库 commit、许可证／改编说明、环境、种子、配置、checkpoint、评估输入和输出；所有屏上精确数值可回查。

## 动画通则

- 以输入→运算／状态变化→输出构成可视化。代码旁边不是终端截图，而是该代码的实际输入与结果。
- 稳定保留坐标轴、类别顺序、棋盘和对象身份。更新用位移、宽高、旋转、路径进度的连续插值；数字用等宽数位，避免文本宽度抖动。
- 柱宽和标签用同一插值值；最后停在真实记录。图片、响应和结果切换共用进度；切换期间不把新图片标签配给旧的稳定数值。
- 随机性在实验产物中固化。累计点数、轨迹和树统计按保存记录推进，重渲染同一帧得到同一状态。
- 让每页有说明机制的变化，同时留出清晰阅读区间；不要让所有元素不停漂移。没有新教学信息的循环旋转不算丰富。

## CNN：从看见输入到检查泛化

| 内容 | 画面必须建立的对应关系 | 易错点 |
|---|---|---|
| 输入 | 实际 CIFAR-10 图片、32×32 网格、RGB 三通道和选定像素 | 高清概念猫不能冒充 32×32 实验输入 |
| 卷积作用 | 同一局部核扫不同位置，输出响应在对应坐标产生；先解释局部结构与权重共享的价值 | 只算九个数字，不说明为何算、算完得到什么 |
| 卷积计算 | 放大真实窗口，乘权重、按通道求和加偏置，再映射响应图像素 | 忽略通道、stride、padding 或混淆手工边缘核与学得权重 |
| ReLU | 对同一真实响应逐位置展示负值置零、正值保留，再显示结果图 | 只有函数曲线，和实际图像脱节 |
| 池化 | 实际窗口聚合到一个输出位置，结果拼成尺寸更小的图 | 把 max pooling 画成求均值，或声称其必然完全平移不变 |
| 网络拆解 | 同一输入逐层对应真实 conv／relu／pool／分类输出，标注实际维度 | 任意换六张好看的纹理声称真实特征 |
| 预测 | 十类完整分布，猫狗可突出；图片与概率共同平滑更新 | 将猫狗两项重新归一化却说是原模型概率 |
| 训练代码 | 正在执行的 3–8 行代码、对应真实前向／损失／更新结果同步 | 高亮步骤与输出先后不符；用摆动条形图代替真实结果 |
| 泛化 | 训练／验证／测试分开，曲线、混淆矩阵、正确与失败样本可追溯 | 用少数漂亮样本证明模型普遍可靠；提前写成功结论 |

扫描演示说明是机制放慢展示；GPU 并非必须按动画顺序逐个像素计算。特征图若独立归一化以便阅读，注明显示归一化，不比较为绝对强弱。遮挡实验只陈述这一输入下的输出变化，不能直接称为因果解释。

第一章的 20 epoch、三个种子和教程双卷积网络属于该章实验配置；其他课按目标选择。先读取运行产物再写结论，不擅改数据凑目标准确率。

## DQN：状态、行动和反馈在同一时刻

- 明确 CartPole 输入为位置、速度、杆角、角速度四个数；动画只是状态可视化，不暗示 CNN 接收摄像头画面。
- 同一条记录驱动车位置、杆角、动作方向、奖励、终止、两侧 Q 值。相邻物理步可插值，但累计回报只在真实步发生时更新。
- Bellman 目标与本次真实转移并排：当前状态、选中动作、奖励、后继状态和目标值；分别解释终止与时间截断。
- 经验回放显示保存的转移如何被抽样，目标网络显示为什么稳定学习目标；颜色和状态 ID 贯穿。
- 随机、早期、训练后三种回放公平比较，保留失败回合、多种子评估和方差。平滑曲线标窗口且仍提供原始数据；高奖励不等于通用智能。

## 棋盘、MCTS、AlphaGo 与 Zero

- 棋盘和搜索树同屏，树的每条动作边对应棋盘合法落子；选中分支高亮与棋盘回放共享步骤 ID，不能让观众自己想象分支是哪步棋。
- 棋子由上方连续落至实际空位，有克制的减速与影子；模拟棋子、当前实际局面和确定落子用少量明确的材质／透明度区分，不留下难辨重影。
- 选择→扩展→模拟→回传围绕同一局面演进，树边逐步展开、访问次数增加、价值统计按记录更新。回传路径可用光点沿边返回，稳定节点不反复淡出。
- 校验即时胜、必须防守、满列、终局、先后手、行列方向；搜索预算增加不保证每局更好。
- OpenSpiel 随机 rollout MCTS 是教学实验，不是 AlphaGo 棋力复现。说明神经网络部分的来源与原理示意身份。
- AlphaGo 2016 与 AlphaGo Zero 2017 使用独立的流程和清楚的差别。2016 解释监督／强化学习策略、价值和搜索的组合；Zero 解释从自我对弈、搜索改进策略到训练更新的闭环，避免把人类棋谱监督阶段画进 Zero。
- 两段都要有实际状态推进：候选分布如何引导搜索、局面价值如何参与评估、自我对弈记录怎样回到更新。不用一幅静态结构图撑完整段旁白；可在真实论文图聚焦后接同构的原创机制动画。

## 其他章的迁移

沿用“同一对象＋可追溯状态＋因果动作”的方法，不照搬 CNN 三列布局。扩散展示每步去噪对应图像状态；Agent 展示真实工具输入输出与检查；世界模型和机器人展示预测候选到行动反馈。代码、公式、原论文和教学重构分别标清来源，付费生成不改实验数字和论文文字。
