# 视觉、文字与品牌

## 风格目标

低饱和、深色、有景深的科技纪录片。画面层次来自主体、距离、光线和真实机制，不靠密集 HUD、玻璃卡片、霓虹边框、装饰数据或闪烁制造“科技感”。背景继续运动但不与讲解抢注意。

数值以 1920×1080 逻辑画布为基准，4K 整体映射到两倍输出；不要只放大字体而保留背景和坐标。完整默认值见 `assets/style-tokens.json`。

| 元素 | 起始建议 |
|---|---|
| 背景 | `#050b11`，深青体积光 `#16313a` |
| 主文 | `#f8efdb`，Noto Serif SC，标题字重约 600–650 |
| 次文 | `#b6ccd0`，Noto Sans SC |
| 强调 | 金 `#d9bb8e`、青 `#91cdd1`；同镜少量使用 |
| 片头标题／章标题 | 72–84 px／约 76 px |
| 片尾主片名 | 136–154 px，按长度调整 |
| 章内技术名 | 44–60 px；长英文手动换行或改排版 |
| 解释短句 | 正式课重点约 34–40 px，次要标签约 28–32 px |
| 字幕 | 44–48 px，行高约 1.5 |
| 来源 | 24–28 px；必要的信息应可读 |

不把缩小字体作为信息过密的首选修复。先缩短文案、延长时间、拆成顺序动画或调整构图。中文标题适量字距 2–8 px，英文不要机械照搬同样字距。用细微材质渐变和软阴影，避免厚描边、凸起 3D 字、强扫光。字体随项目保存许可证。

## 构图

参考安全区：水平 100–110 px，顶部约 90–120 px；字幕底距约 85 px；来源位于约 y=867 的右侧。上下 48 px 遮幅是本片选择，不是所有视频必备。

六章主体采用全屏环境。左侧标题与机制图占用负空间，右侧或远景主体承担案例，二者通过视线、光线、运动或共同物件关联。左侧不是一块嵌入屏幕；不用粗边框和硬色块分割。为左文可用柔和横向暗部渐变，但不得把主体抹黑。

每镜检查：标题、技术名、机制图、字幕、来源五者的包围盒，以及主体与运动轨迹经过的区域。检查整段而非单个好看的帧。复杂机制清晰停留时允许背景缓动，不要求所有元素永不停歇。

## 片名与 Logo 一体化

品牌为 **rainbow鱼**，保留大小写和汉字。用户原图可描摹为透明矢量轮廓，图形比例不拉伸。随附 SVG 用于该用户品牌；新客户项目应换成对应授权标志。

推荐结构：一个父组件内依次放署名行（小轮廓＋rainbow鱼）、主标题、可选副标题。片头随主体留白左对齐，片尾与主片名共轴居中。署名相邻间距约 12 px，与片名之间约 14–18 px 的布局间距；实际字体行盒需视觉检查。署名文字约 27–29 px、图形高约 40–46 px。

片名署名组合的父组件承担 opacity、轻微位移、缩放收定、少量入场虚焦；这个模式不额外给子标志做延迟补贴。共享材质的象牙金渐变可略带青色，图形亮度服从标题层级。示例：显现 58 帧、收定 100 帧、退场 48 帧；缩放由 1.008 到 1，位移约 8 px。它们是起点，不是硬编码要求。

品牌融合失败常见原因：标志在标题出现后突然补入、下方留空过大、单独悬浮在粒子球下、尺寸太大、明亮多彩质感与场景不同。修复共享构图与运动，不只调低不透明度。

### 正式教学的品牌模式

按当前第一章偏好，正文保持角落的图形＋rainbow鱼：1080p 起点右距约 90 px、顶距约 70 px，图形高约 48 px、署名 30–32 px、字重约 600，整体约 220×50 px；按实际字体测宽并避开标题。低饱和金灰、清楚但不抢焦点，贯穿全片的一个层，不随每节反复出入。

片头／片尾可将同一标志放大为主构图：真实路径缓慢描摹，路径接近完成后下方自然出现 rainbow鱼。这是用户明确偏好的顺序，区别于无理由延迟贴 Logo。用 SVG pathLength／dashoffset 或轮廓遮罩显露原标志，不能把整个标志变成含糊的描边替代。建议数秒完成、最后清晰停留约 1–2 秒，跟随旁白和音乐调整；不要拖成长时间空白。

主标志出现时隐去角落副本，结束后让角标接续；不同时出现两个品牌。共用背景、光照、色彩、空间轴线，慢速描摹无加速扫光、爆闪和彩虹霓虹。片尾允许增加数秒完整收尾，但同时延长时间线和声音尾部。

### 地图和信息锚点

六章地图的文字、节点、连线端点应从同一布局数据计算，共用变换容器；不能分别手写三套坐标。下方小节点用实际章内技术名（第一章含 CNN、DQN／深度强化学习、搜索与 AlphaGo），不要只有无含义的小点。入场中、收定后、退场中都检查文字与点线对齐。

构图紧张时顺序揭示内容，而不是堆出更多侧栏。资料案例要重构到同一教学空间：重排主体、视角、遮挡与流程关系；只给现成视频加颜色滤镜和矩形框达不到要求。背景高亮边缘不得穿过重要文字，先换主体位置或留白，再用柔和局部暗部承托。

## 左侧教学动画

参考后两章干净的机制呈现：用真实状态变化、连线、空间结构和少量标签传达信息。去掉 LIVE、模拟时间码、状态灯、容器边框、扫描装饰。说明算法必要的扫描动作可以保留，例如卷积核滑动；不要把必要机制也误删。

π 实验的点必须增加，计数和曲线必须同步；机器人动作应由一个贯穿章内的状态机推进。丰富程度来自有意义的运动，不来自更多小字或层层仪表。
