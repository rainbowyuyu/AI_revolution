# 叙事与生产流程

## 1. 定位与信息顺序

预告片需要让人期待后续内容，而非在几分钟内讲完所有论文。用“观众会获得什么能力或理解”串联技术，不写成 AI 论文编年史，不声称所有技术直接继承。

开头优先顺序：具体能力／矛盾或问题 → 我要做一个完整系列 → 大章地图与每章小主题 → 展开关键机制 → 系列承诺和片名 → 可选原始论文尾声。不虚构发布日期。

开场例句：“如果一句话，能让机器人完成一个动作；一个想法，能变成可以探索的世界。背后的智能，究竟怎样发生？”随后明确：“我准备制作一个完整的系列，分成六个章节……”例句是本片参考，不作为所有项目的固定文案。

允许为内容和自然语速延长时长。当前案例 214 秒不是新片固定长度；最早的 120 秒、3600 帧、430–500 字旁白限制已经不适用于当前版本。

## 2. 六章内容骨架

| 大章 | 章内内容 | 观众带走的问题 | 可贯穿的视觉锚点 |
|---|---|---|---|
| 看见与选择 | CNN、DQN／深度强化学习、搜索与 AlphaGo | 怎样从像素提取特征，再结合搜索选择动作？ | 图像网格 → 局部特征 → 棋盘分支 |
| 从识别到创造 | GAN、Diffusion | 对抗反馈与逐步去噪分别如何产生内容？ | 候选分布 → 噪声场 → 空间形体 |
| 语言连接万物 | Transformer、LLM、CLIP、指令微调／RLHF、多模态 | 上下文、图文对齐和反馈如何支持协作？ | 同一句机器人指令与同一只杯子 |
| 走进三维世界 | NeRF、3DGS、4DGS | 照片如何成为新视角和动态空间？ | 同一主体、绕行摄影机与采样光线 |
| 从回答到完成 | 推理模型、Agent | 答案怎样通过检索、代码和反馈得到验证？ | 可见任务流程与真实 π 实验 |
| 预测，然后行动 | 世界模型、Diffusion Policy、VLA、Physical AI | 预测如何连接感知、语言和动作？ | 同一桌面任务：预测 → 轨迹 → 抓取 → 再观察 |

总览分两组，每组三章，留时间阅读每章 2–3 条小主题。不把 18 个标签塞在一个短镜头里。正文一章一个标题，主题在章内自然切换；不为每个名词另起一张章节卡。

两组三章是可用布局而非唯一形式；连贯路线也可。六章是系列组织，章内技术不是再承诺 18 个视频。正式课的长篇结构见 [长篇教学叙事](teaching-narrative.md)。预告尾声默认论文汇总，正式课按讲解需要局部聚焦，见 [论文展示](papers.md)。

## 3. 制作阶段与实际产出

| 阶段 | 具体动作 | 完成证据 |
|---|---|---|
| 项目盘点 | 读取最新源码、版本说明、原片、截图；标出已授权预算和渲染范围 | 任务单、需要保留与修改的范围 |
| 研究与实验／脚本 | 每项实质论点找到原论文或官方资料；先运行真实实验，再依结果写正式旁白，实验前只写问题和假设 | 来源台账、运行产物、旁白、章内问题 |
| 镜头规划 | 为每镜写入／出帧、运动方向、构图、字幕和来源安全区 | 分镜表，明确转场帧区间 |
| 动态分镜 | 用低成本几何和临时音轨跑完一遍；验证总览、文字量和呼吸 | 可播放 animatic，不能只交静态 storyboard |
| 声音与实验 | 本地分句合成配音，运行并保存真实实验数据 | 音频、时长、数据、日志、字幕对齐 |
| 技术动画 | 制作可解释的机制变化，校验数学与状态映射 | 固定帧可复现的组件或 Manim 视频 |
| 素材重构 | 将资料主体和教学画面在构图层面结合，必要时生成 | 关键帧、原始来源、重构类别 |
| 连续镜头 | 提取实际端点、匹配运动，生成桥接或确定性衔接 | 接缝样帧、合格候选、任务账目 |
| 合成 | 叠加准确文字与公式，混音和字幕，统一颜色 | 可渲染工程 |
| 预览检查 | 类型检查、局部样帧、完整 1080p、核验视频与音频 | 版本化预览、检查记录、待确认事项 |
| 最终交付 | 按已授权分辨率导出，整理工程及资料 | 成片、字幕、声音、论文、台账、重渲染方法 |

## 4. 改版策略

把“高级、自然、丝滑”转化为可检验目标：文字是否遮挡主体，Logo 是否有单独延迟，背景是否突变，图表是否清晰停留，运动是否解释机制，接缝是否重置动作。先修根因，再调整光效。

只改视觉时，不重新合成已经正确的 TTS；改旁白时重新计算字幕与场景边界，不能只替换声音文件。延长章节时同步更新主题切点、镜头路由、转场、总帧数和音频时长。

阶段产物应足够具体供审阅，但不要在用户已授权执行时把每个阶段变成额外审批关卡。当前用户明确的关卡是新版 4K 前确认预览。
