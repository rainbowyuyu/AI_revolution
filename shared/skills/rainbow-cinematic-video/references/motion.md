# 动画、数学与连续镜头

## 帧与状态

Remotion 负责主时间线、合成、文字、来源、字幕与声音；Manim 用于精确公式和技术几何，React/SVG/Canvas 适合轻量机制图。按需要选用，不要求为了“用上工具”把每个镜头都经 Manim 渲染。

所有状态可由帧号重建。区别三个时间：全片帧 `globalFrame`、章节帧 `globalFrame-scene.start`、主题帧 `chapterFrame-topic.start`。主题标签可以重置，贯穿物体、机器人手臂、实验累计状态使用章节时间。Manim 预渲染明确 fps、透明度／底色和精确时长，Remotion 不靠随机播放速度补齐。

用 `interpolate` 的 clamp 和平滑 easing；阅读类推进可从 `Easing.bezier(.45,0,.55,1)` 起步。位移、旋转、缩放共享摄影机意图，不同时大幅旋转、横移、模糊。字的入场常用 6–18 px 位移而非大弹跳。

## 各技术必须表达的机制

| 内容 | 合适的动态表达 | 需要避免 |
|---|---|---|
| CNN | 同一卷积核扫描；输入、响应与组合特征对应 | 只有无关闪亮格子 |
| AlphaGo／深度 RL | 局面、策略候选、价值评估与树搜索 | 将 AlphaGo 简化为纯穷举或仅 CNN |
| GAN | 目标／生成分布、判别反馈与更新 | 暗示必然稳定收敛 |
| Diffusion | 固定噪声样本逐步去噪，噪声预测对应状态变化 | 只交叉淡化几张图并称为算法实验 |
| 注意力 | 有语义联系的 token、归一化权重与加权输出 | 把示意权重说成真实模型实测 |
| LLM／CLIP | 上下文概率、图文编码与语义邻近 | 把 embedding 当二维真实语义坐标 |
| SFT／RLHF | 示范、偏好信号、优化结果，保留两者差别 | 把全部训练方法归为一个评分按钮 |
| NeRF | 光线采样、辐射／密度与体积积分 | 误用高斯点表示原方法 |
| 3DGS／4DGS | 高斯位置、协方差、颜色、透明度；时变形变 | 声称高斯是物体实际微粒 |
| 推理／Agent | 提问、检索、运行代码、检查、纠正 | 伪造模型内部思维过程 |
| 世界模型／动作 | 未来候选、轨迹去噪、指令与感知、动作闭环 | 将未来预测能力等同已实现通用控制 |

预告默认短展示两处公式：`softmax(QKᵀ / √dₖ)V` 与选定扩散算法的去噪关系。先说明图形意义，再出符号。扩散采样式须注明对应参数化／采样方法，不把不同 DDPM、DDIM 公式混用。

π 实验使用真实固定种子样本，`π̂=4*N_inside/N_total`。保存样本／累计记录；按章节时间选前 n 个样本，点数、圆内数、估计和误差曲线同时变化。演示结果从数据计算，不能装饰性手写一个接近 3.14 的数。

## 素材之间的连续性

1. 先确定共同锚点，例如棋盘线变为空间网格、噪声点变为高斯场、同一杯子从识别延续到抓取。概念相连不等于算法直接继承。
2. 锁定相邻镜头的实际摄影机方向、主体位置、大小、曝光和动作阶段。
3. 从已用素材或干净合成层提取真实出／入帧，去掉文字、公式、字幕和来源，作为桥接端点。
4. 有授权时生成首尾帧桥接；摄影机提示词明确主体身份、运动方向、机位与相同桌面关系，避免随意生成新物体。精确文字在 Remotion 最后叠加。
5. 正常速度检查，再抽样每 3–6 帧；接缝两侧至少各看 0.5 秒。检查主体熔化、位置跳跃、动作倒退、端点停顿、曝光闪变和字幕穿帮。
6. 桥接失败先改构图／端点。到预设尝试次数或预算上限后采用匹配运动、程序几何变形或稳定遮挡转场，并记录真实方法。不要声称所有段落都使用首尾帧生成。

生成的 5 秒桥接应有自己的叙事节奏，不能为藏接缝挤压成极短加速闪切。章节之间不加切换提示音。

## 补帧边界

光流／运动补偿仅适合相邻内容相似且运动连续的镜头内部或已匹配的端点。不能用补帧解决棋盘与冰山等完全不同构图之间的语义跳变；先桥接或重构中间段。检查细线、手指、棋子和遮挡边缘的光流重影。

端点 RGB 差异小只表明颜色接近，不证明运动自然。不要仅复制最后一帧填空。检查路由半开区间 `[from,from+duration)` 的覆盖，确保没有一帧空洞、错误循环或抢先进入下一素材。

## Remotion 时钟与闪动的具体排查

- 视频先用 `Sequence from={sceneStart}` 获得局部时钟，再用固定 `trimBefore`／对应版本 `startFrom` 裁源片；两种属性按项目 Remotion 版本选择。不要把 `globalFrame` 同时加到播放进度和动态 `startFrom` 中，否则双重推进、越界、冻结。
- 校验 `裁剪起点 + 所需源帧数` 不超过源素材长度，考虑 playbackRate 与原始 fps。没有实际运动的最后一帧不能称为生成桥接。仅用于短暂端点匹配的定格可显式 `Freeze` 并记录，不能用它填几秒空档。
- 同一实体使用稳定 React key；数组排序、floor 阶段、取模、重新挂载可能造成跳动。阶段切换保留共同的输入图、坐标系和节点，不每句从零入场。
- 查层级和遮罩：背景过渡在主体下方；全文字／Logo／字幕不跟着视频黑场消失。两场高对比文字不要同时高不透明度叠加。
- 棋子和数值不能用每次变化都 opacity 0→1 的方式更新。使用连续 transform、路径进度和柱宽，离散标签在稳定状态附近切换。
- 时间线有较长无口播段时判断它是否承担阅读或运动信息；如果只是等片段播放完，缩短或重排。不用慢速生成桥接掩盖无内容等待。

## 生成转场的使用强度

开场可使用吸引人的环境总览镜头，不能吞掉任务说明；教学内部优先沿同一物体连续变形。用户要求某接缝用生成时，在现有授权范围内提取真实端点制作，不能把旧素材调速或滤镜改色说成新增生成。生成只承载环境和概念过渡，叠加层的图表／棋谱／实验响应保持确定且可信。

提示词与验收同时约束主体身份、输入输出机位、运动方向、材质、照明、文字留白、无新增文字／Logo。不同内容确需语义桥接时，以匹配构图的关键帧重构后生成；仅改滤镜不算和教学融合。模型、费用与尝试上限遵循当前任务台账，不从旧计划自动取得新的预算授权。
