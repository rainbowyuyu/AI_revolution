# 本地配音、字幕与声音

## 本地 TTS

本片基准为 `RAINBOW_TTS_ROOT` 指定的目录 内 Qwen3-TTS 和用户既有声音参考。新工程通过配置指定模型与参考音频，先检查可用性，不直接运行绑定另一部影片输出路径的脚本。不把个人声音参考复制进通用 Skill。

1. 旁白分场景、分句，口语简洁，给观众看图的时间。
2. 区分显示文本与朗读文本。建立语境读音表；不把英文名字任意翻译为中文含义。用户要求英文读音的术语保留英文发音，用支持中英混合的同一声音和完整短句合成，字幕保留标准写法。
3. 用现有虚拟环境和模型，分段生成自然语速音频。缓存键包括文字、模型版本、声音参考、种子和影响输出的采样参数；不要错误复用旧句。
4. 先量真实时长，再安排停顿与镜头。变速限定约 ±5%；超出时改句子或延长内容，不生硬加速。
5. 保存原始合成、清理版本和最终人声，逐句复听术语、停顿、字尾。

## 本系列重点读音与中英衔接

| 显示文本 | 朗读目标／检查重点 |
|---|---|
| AlphaGo | 读英文名字 Alpha Go；不读成“Alpha 围棋”，不改变字幕拼写 |
| AlphaGo Zero | 英文名字连贯，Zero 不突变成另一音色 |
| ReLU | 作为完整术语读，通常按 REE-loo；不拆成“re、L、U” |
| rainbow鱼 | 作者名；rainbow 的英文部分和“鱼”连成自然署名，不逐字母念、不过长停顿、不另插一段陌生声音 |
| CNN、DQN、RGB | 按缩写自然读；首次可先讲中文含义，再给缩写 |
| 行、列 | “三十二行”读 háng，“运行”读 xíng；不要全局把同一个字改为同一读音 |
| 卷积、池化、策略、概率、回传 | 重点检查技术词是否被错断词，声音是否与字幕一致 |

先合成含上下文的短句试听，避免只测孤立单词。中英文接缝不靠硬拼外部音色修复；优先整句重合成。确需同声源拼接，在自然停顿处剪接并轻柔交叉淡化，不能交叉吞掉爆破音／字头。允许配置发音提示或模型支持的语音标记，最终以实际听感为准，不把音标直接送入不支持的 TTS。

## 降噪与自然度

先分辨持续底噪、句首呼吸、TTS 毛刺、接缝咔哒和配乐掩蔽。保留 raw，对受影响部分做适度降噪、去直流／必要低切和短边缘淡化；不一律强门限剪静音。强降噪造成金属声、水声、齿音损伤时退回较轻处理或重新合成。

清理后与 raw 等响度 A/B 复听，特别检查英文尾辅音、轻声字尾、句首和拼接点。机器噪声指标下降不代表声音更自然。纯画面修复无需重新降噪或改变已有配音；新旁白的响度和音色需与上下段一致。

## 截断故障排查

同时检查：模型是否生成完整句子、token 上限、静音修剪、固定音频偏移、场景出点、总音频长度。音量阈值会误切轻声字尾，修剪后留约 0.25–0.35 秒余量；本片使用约 0.32 秒。末词结束后至少保留约 0.15 秒可用尾部，具体按听感调整。

若旁白“动画与实验中展开”等句尾被截断，不能只延长视频却仍播放已损坏音频。复听 raw 与处理后音频，定位在哪一层丢失，再针对该句重做。

## 字幕与对齐

用本地 Whisper 字词时间辅助对齐，目标明显偏差不超过约 150 ms。专有名词识别错误可校正，不直接把 ASR 当最终文字。比较预期句子与识别覆盖率，发现缺句先检查音频而不是强行改字幕。

字幕从正式旁白生成，段落区间不重叠、不超出音轨或时间线。通常一到两行，中文约 15–22 字／行按版面调整，避免人名和术语拆坏。语音校验的字符匹配高不代表发音正确，仍需听审。

## 配乐与混音

使用明确可用的纯音乐或项目内原创声轨，保留授权／创作来源。低频脉冲、轻微环境与持续声床可连接章节；本风格不加入章节撞击、whoosh 或提示铃声。生成视频自带声音默认不进最终混音。

旁白开始前轻柔压低配乐，结束后缓慢恢复，避免 pumping。建议 48 kHz 音频，保存 narration、score、premaster、master。双遍测量响度，目标约 −14 LUFS；预留母带峰值约 −1.5 dBTP，最终 AAC 编码后复测，真峰值不高于 −1 dBTP。检查的是最终 MP4 而不只是 WAV。

纯视觉改版且时长未变时复用已检查 master。时长、旁白或停顿改变时重新对齐和混音，避免旧音乐尾段或字幕与新视频错位。
