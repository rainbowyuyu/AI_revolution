# rainbow鱼 · 电影感科技视频

把观众带入一条可理解、可验证的能力演进路线。画面服务讲解，技术机制真实，声音自然，摄影机与文字构成连续的叙事；避免把科普做成名词目录、监控面板或素材拼贴。

适用请求示例：`使用 $rainbow-cinematic-video，把这个主题做成同风格系列预告，先出 1080p。` 或 `使用 $rainbow-cinematic-video，优化当前片子的 Logo 融合、教学动画和论文聚焦。` 若仅要求整理规划／创建 Skill，就只交付文档或 Skill，不启动成片渲染与付费生成。

本 Skill 归纳《AI 进化史》预告及第一章《看见与选择》的多轮修改。**最新用户要求优先；默认值不强制新片沿用同一内容、时长、预算或设备。** 总览 V11、第一章 V9 是不同工程；技术检查通过不等于用户已认可审美或授权新版 4K。用规则减少已知返工，不能承诺一次生成就免于审阅。

## 核心制作约定

- **正式课先交代要解决什么。** 很早显示章名、具体任务和核心技术，随后每部分依次讲“目标 → 困难 → 方法 → 实验观察 → 下一步”。CNN、DQN、搜索只是第一章示例，不把三种技术硬套给其他章节。
- **每句旁白有对应的画面证据。** 实验总览、分类引言、像素讲解分别设计；相同 `visual` 标签不代表内容相同。正式教学／音画修复必读逐句音画契约；整章制作同时读取长篇教学叙事和实验可视化。
- **先抓住注意力，再说明系列承诺。** 开场展示直观能力或提出具体问题，接着说明未来要制作完整系列，再短暂展示大章及章内内容。AI 进化史按六章组织，18 个技术主题保留为章内内容，不再承诺“18 个视频”。
- **先机制，后术语与公式。** 每次让观众看懂一个变化。公式出现时对应当前图形；标签不堆满画面。
- **统一空间。** 全屏环境、主体、机制动画和文字共享色彩、光线及构图。重绘须重新安排主体、负空间与教学关系，不能只给小视频套滤镜或加边框。
- **克制的电影感。** 深蓝黑、象牙白、低饱和金与青色；主标题有层次，重要文字足够大。移除没有解释作用的 LIVE、时间码、扫描线和状态灯。
- **Logo 属于画面。** 名称为 `rainbow鱼`，使用用户轮廓；正式课默认角落常驻，片头片尾可慢速路径描摹、随后出现署名，整组共享构图与退场。不要把有意的描摹顺序误删，也不要做突然补贴的徽标。详见视觉规范的品牌模式。
- **运动必须解释变化。** 图像切换、概率柱、棋子、搜索统计使用连续位置／数值插值；不靠反复淡入淡出、闪烁或旋转装饰冒充动态。真实数值只取保存的实验产物，插值中间态不宣称新增实测。
- **主播口播，自然中英衔接。** 去掉“本片将”“避免观众”“别急着”等制作或劝导口吻；保留有用途的个人系列承诺。AlphaGo、ReLU、rainbow鱼及行列等词需语境读音表和实际复听，不能只靠 ASR。
- **所有动作由帧号或固定数据驱动。** 禁用依赖真实时钟的 CSS 动画、无种子随机和 `Date.now()`。局部主题更新不能无意重置持续实验或机器人动作。
- **来源简洁可见，证据完整留档。** 官方实拍、教学重构、原理示意与真实实验分别说明，不能把生成概念镜头当成产品实测。本系列不反复显示“AI 生成的画面”字样，采用准确的“来源：机构｜教学重构／原理示意”等必要标注。
- **先预览再高分辨率。** 延续本系列时先交付 1080p，用户确认当前版本后才导出新版 4K。已有明确授权不重复询问；任务若已明确要求并授权最终 4K，按该要求执行。

## 执行闭环

正式课按「问题与来源 → 真实实验及结果审阅 → 正式口播 → 配音测时与逐句分镜 → 技术动画与素材 → 实际交接帧转场 → 字幕与声音 → 关键帧和连续播放检查 → 完整预览与成片核验」推进。实验前可做假设性草稿和低成本动态分镜，不能预写成功结论。预告只执行与其论点相关的实验；局部修复只重做修改影响的步骤。

每个镜头记录：帧范围、观众应理解的要点、旁白、视觉变化、真实数据或示意、素材来源、交接锚点、字幕安全区、验收状态。重叠转场占用既有时间线，不额外偷偷增加总帧数。

付费生成是可选制作手段，不是此 Skill 的必经步骤。新片沿用当前授权预算而非历史预算；模型、价格和地域在调用前核实；在途任务计入上限；未知状态先查询任务，不重复提交。不得把密钥、密码、服务器凭据装入 Skill 或交付包。

## 随附工具与资产

- `assets/rainbow-vector.svg`：从用户图形取得的可缩放轮廓，只用于用户品牌；并非外部商标的通用模板。
- `assets/style-tokens.json`：1080p 构图基准、颜色、字号与运动建议，供新工程读取或转换为 TS 常量。
- `assets/production-brief.md`：新片／改版任务单与镜头、来源、交付字段。
- `scripts/pdf_focus.py`：**执行工具**。从本地真实 PDF 渲染整页和定位检查图，验证页码、矩形与目标文字并输出哈希。用法见论文参考；依赖 PyMuPDF。
- `scripts/inspect_preview.py`：**执行工具**。读取成片规格、抽取接缝与重点帧、生成带时间标记的联系表，按需完整解码和响度分析；依赖 ffmpeg、ffprobe、Pillow。它不证明审美、读音或技术正确性。

工具不自动下载依赖、不上传素材、不调用生成 API。新工具首次使用可先以现有短样片／单页试跑；输出到本次工程的独立检查目录，不污染 Skill 本身。

已有 Remotion 工程优先复用其渲染脚本和配置。需要更具体的 Remotion 或 Manim API 时查当地文档或适用工具说明；不要为采用本 Skill 强制更换技术栈或装大型生成模型。

## 完成时

提供可直接打开的预览、简短改动说明和实际核验结果。尚未完成的检查、概念画面、原生分辨率限制以及待用户确认的版本状态如实说明。把源代码、旁白／字幕、来源台账、生成账单与重渲染入口留在独立项目中，让下一支视频能延续同一套视觉与声音。
