# 封面与发布材料

本包对应《AI 进化史》总览 V11 与第一章 V9 分类引言修正版。

- [封面总览](封面总览.jpg)：横版、竖版及手机缩略图比较。
- [成品封面](covers/)：每部 16:9 / 9:16 / 3:4 三种版式，各有 JPG 和 PNG。
- [标题、简介与发布建议](发布方案.md)：两平台分别准备首选和备用文案。
- [实际研究与来源](research/封面与平台研究.md)：B 站公开播放数据、抖音官方案例和推荐机制说明。
- [生成与筛选记录](generation-summary.json)：模型、费用预留、成功/失败及选用文件。
- [排版源码](compose_covers.py)：修改标题、字体、品牌与构图后重新输出。

重排依赖：Python、Pillow、NumPy、PyMuPDF；使用同级总览工程的 Noto 字体。放在 AI_revolution 仓库的 `publication/2026-09-23` 时会读取根 `overview/public/fonts`，需先恢复字体素材。`rainbow-vector.svg` 是本作者的既有品牌，不是模型重新造的 Logo。

底图由百炼 Qwen Image 生成，再叠加准确中文文字和品牌。横竖各自生成，不直接裁切横幅去充当竖幅；3:4 版单独调整文字和取景。没有复用他人的封面图作为生产素材。

本次只制作发布材料，尚未代为发布到 B 站或抖音。
