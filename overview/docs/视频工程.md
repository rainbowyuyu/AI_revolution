# 总览 V11 · 视频工程与素材恢复

[返回总览](../README.md) · [共享维护规范](../../shared/docs/MAINTENANCE.md)

本工程负责六章系列的引入、能力路线和文献汇总。当前入口为 `TrailerV11-1080`，1920×1080、30 fps、5,787 帧，共 192.90 秒。依赖锁定在本目录的 `package-lock.json`；V11 仍引用部分较早版本的场景，不能仅按文件名版本号删除代码。

## 1. 恢复素材

在仓库根目录执行：

```powershell
python tools/assets.py status --project overview
python tools/assets.py restore --source-root "<原工程的 video_project 目录>" --project overview
python tools/assets.py status --project overview --verify
```

`source-root` 下需有 `ai_evolution_trailer/`。恢复工具按体积和 SHA-256 检查文件；缺少文件或摘要不符时报告问题，不覆盖已有的不同文件。新克隆尚未恢复大型素材时，状态检查返回 1 是预期结果。默认不恢复单句语音，重新混音时追加 `--include-voice-clips`。

只阅读代码和进行 TypeScript 检查不需要大型素材；渲染需要字体、媒体、论文页和音轨完整。完整素材分类和登记方式见[共享素材说明](../../shared/docs/ASSETS.md)。

## 2. 安装、预览和输出

使用 Node.js 22 和 npm。在仓库根目录进入本工程后运行：

```powershell
Set-Location overview
npm ci
npm run check
npm run studio
```

Studio 选择 **`TrailerV11-1080`**。以下命令在 `overview/` 内执行：

```powershell
npm run stills
npm run render:intro
npm run render:papers
npm run render
```

完整输出：`output/AI进化史_V11_预览1080p.mp4`；代表帧和局部预览位于 `output/v11/`。当前 `npm run render` 指向 V11 全片，不要用旧脚本替代这一入口。仓库不提供成片下载，当前合成入口为 1080p。

## 3. 检查当前修改

先检查代表帧和局部预览，再渲染全片。完整成片可在安装 FFmpeg/ffprobe 后检查：

```powershell
python scripts/qa_v11.py
```

脚本核对视频规格、全片解码、字幕区间、语音尾部和编码后响度，报告写入 `output/v11/qa-v11.json`；它也导出片头与文献汇总预览。口播听感、接缝和画面遮挡仍需实际查看。

V11 原制作记录的结果为 −14.15 LUFS、−1.45 dBTP。该数字属于原成片，不能用来替代修改后的测量。修改旁白和背景音乐时按[本工程声音与同步说明](声音与同步.md)更新切点、字幕与动作锚点。
