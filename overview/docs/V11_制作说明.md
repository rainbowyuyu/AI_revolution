片头直接说明创作计划：把 AI 历史做成可视化拆解，围绕发展过程、原理与用途三个问题展开。新增五句同声线口播，前约 15 秒建立主题，随后按旁白分两组展示六章。

背景使用已有万相生成素材：猫与实验桌连续摄影机、世界模型概念场景、机器人概念场景。首镜做同镜头光流慢速补帧；跨场景为 26／32 帧的柔和叠化，再溶入动态章节总览。没有新增 API 生成或费用，也没有把普通叠化宣称为首尾帧生成。

六章正文从新时间线 32.90 秒开始，沿用 V10 原 32–175 秒的画面、旁白和来源，整体顺延 0.90 秒。进入正文前最后 60 帧使用同一段 vision 视频，边界两侧共享连续的源视频帧。

文献汇总从 175.90 秒开始，持续 17 秒；删除旧版 39 秒逐篇阅读。10 篇真实 PDF 首页错落叠放，前景清晰、后景轻虚焦，右侧只列简称、第一作者与年份。原论文链接详见 V11_参考文献.md。

## 重渲染

```powershell
npm run check
node scripts/render_v11.mjs stills
node scripts/render_v11.mjs full
python scripts/qa_v11.py
```

需要重做新口播时先设置 RAINBOW_TTS_ROOT，激活自己的本地 TTS 环境（详见仓库 docs/AUDIO.md）：

```powershell
$env:PYTHONUTF8='1'
python scripts/v11_voice.py
python scripts/v11_audio.py
```

说明：图片和音轨均在 public；重做口播后必须核对新阶段时间，不能盲目复用旧跨场景切点。光流处理仅用于同一连续镜头内部，不用于世界到机器人之间的语义变形。
