# 总览 V11 · 声音、字幕与同步

恢复 `public/audio/v11/` 的已核验主音轨即可预览，不需要重新生成语音。新句记录在 `public/audio/v11/voice.json`，当前字幕在 `src/captions-v11.json`，观众可读版本在 [supplements/](../supplements/)。

## 重新制作声音

使用独立 Qwen3-TTS 环境，TTS 模型和私人声音参考不进 Git。设置 `RAINBOW_TTS_ROOT`，该目录沿用原环境的 `models/Qwen3-TTS-0.6B`、`work/clone-reference.wav`、`work/clone-reference.json`。环境需要 torch、qwen_tts、numpy、soundfile；对齐或混音还可能需要 scipy、faster-whisper、FFmpeg 和本地 Whisper 模型。

以下命令在 `overview/` 内用自己的 TTS 环境运行：

```powershell
$env:RAINBOW_TTS_ROOT = "<自己的 TTS 环境目录>"
$env:PYTHONUTF8 = '1'
python scripts/v11_voice.py
python scripts/v11_audio.py
```

这些命令会重新生成声音及相应记录。重新测量每句时长后，再更新 `src/timeline-v11.json`、字幕和画面切点；不能只替换 WAV 后继续使用旧节奏。

## 随片文本与验收

在仓库根目录运行 `python tools/export_supplements.py` 可从当前登记时间线导出字幕和口播。该工具不重新识别语音，不验证发音或同步。

总览原 V11 的五句新增口播由 0.45 秒持续至 31.07 秒，详细句子和时码见 [V11 制作记录](V11_制作说明.md)。修改后逐句检查尾音、中英文衔接和关键视觉对象的出现时机；尤其检查六章名称的阅读时间与进入正文的切点。

口播、降噪、混音、字幕安全区等通用标准见[共享声音规范](../../shared/docs/AUDIO.md)。成片检查使用 `python scripts/qa_v11.py`，编码后重新测量响度，并实际复听接缝。
