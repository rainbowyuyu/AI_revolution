## 一条连续的路线

```mermaid
flowchart LR
  A[看见与选择] --> B[从识别到创造]
  B --> C[语言连接万物]
  C --> D[走进三维世界]
  D --> E[从回答到完成]
  E --> F[预测，然后行动]
```

这条路线表示系列的讲解顺序。每章围绕一个实际问题展开，不把所有技术画成一条直接继承链。

| 影片区间 | 这一段讲什么 |
|---|---|
| 0–32.9 秒 | 用三个问题开场，展开六章路线 |
| 32.9–175.9 秒 | 从视觉、生成、语言走向空间、工具与行动 |
| 175.9–192.9 秒 | 十篇真实 PDF 首页与作者、年份汇总 |
