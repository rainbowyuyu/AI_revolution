# 预测，然后行动 · 制作计划

## 具体目标

从观测和目标生成动作，在模拟环境中验证机器人是否能完成任务。

## 教学推进

1. 从目标物体与动作后果进入。
2. 区分世界预测与控制策略。
3. 从动作去噪解释 Diffusion Policy，再连接语言条件。
4. 比较成功、失败与分布外情况，区分厂商演示和本地实验。
