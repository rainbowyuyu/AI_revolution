# 走进三维世界 · 制作计划

## 具体目标

用同一物体的多角度照片，重建一个能转动视角的三维场景。

## 教学推进

1. 从移动相机后应看到什么提出任务。
2. 沿视线采样解释 NeRF 的体渲染。
3. 用投影椭圆解释 3D Gaussian Splatting 的表示。
4. 为变化中的场景引入时间，并展示重建失败和评价视角。

## 候选实验（未执行）

- 公开小场景的新视角合成
- 固定相机轨迹对照 NeRF 与 3DGS，单独计划动态场景

实施前锁定仓库 commit、许可证、数据与种子；保存真实指标和失败案例。此处没有承诺模型效果或成本。

- 3D Gaussian Splatting: Kerbl et al., 2023
