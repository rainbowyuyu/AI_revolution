## 分词与因果注意力

字符BPE使用五种短句各重复三次，执行14轮合并。保存的词表中“红伞”编号为21；编号只是查表索引，没有大小或语义距离含义。两条示例都能由词元完整还原输入。

注意力实验的Q/K/V各为4×2，输入位置对应“红伞／靠在／蓝色／门边”。点积产生4×4分数，经过缩放、因果遮罩与softmax，再乘V得到4×2输出。每行权重和为1，未来位置权重为0。

证据：[tokenization.json](../results/tokenization.json)、[causal_attention.json](../results/causal_attention.json)。

后续公式动画另用六维输入、6×2投影矩阵和六词元注意力；这些输入与前一个四词元实验分别保存在 [formula_examples.json](../results/formula_examples.json)，不要将两组数字混用。投影矩阵是按目标结果构造的教学参数，并非训练权重。

## 下一字符统计基线

| 项目 | 设置或结果 |
|---|---|
| 语料 | 4种伞×4个位置×4种结尾，共64句 |
| 拆分 | 枚举下标能被5整除的句子作为留出集；51句训练、13句留出 |
| 词表 | 40个字符或结束符 |
| 上下文 | 最长前2个字符；未见上下文回退 |
| 平滑 | 每个目标计数加0.1 |
| 评估位置 | 234个，包含句尾结束符 |
| unigram平均NLL | 3.45096056 |
| trigram平均NLL | 0.57819300 |
| “雨后的红伞”后“靠”的概率 | 0.75625 |
| 采样 | 固定种子12；温度0.5、1、1.5 |

NLL采用自然对数，数值越小表示这批留出目标的平均预测概率越高。这个结果来自固定模板语料，不能与GPT或开放语料上的分数直接比较。

证据：[next_token.json](../results/next_token.json)、[sampling_trace.json](../results/sampling_trace.json)。轨迹包含每一步随机数与完整分布，核验器按种子逐步重放。高概率不表示每次采样必选该候选。

## CLIP：为什么照片里有车，模型却选错了？

原图的红车在画面边缘。官方默认预处理会中心裁剪；模型收到的224×224输入中，车被裁掉了。另一种条件先填边保留全图，再用同一个模型和处理器进行检索。

| 红车查询 `a red car on a street` | 红伞蓝门图余弦分数 | 红车图余弦分数 | 两者中谁更高 |
|---|---:|---:|---|
| 默认中心裁剪 | 0.231213 | 0.228902 | 红伞图 |
| 全图填边后再预处理 | 0.258643 | 0.318590 | 红车图 |

这是三张固定生成候选图上的检索对照，不是开放域识别准确率。`candidateSoftmax` 是当前候选集合内部的归一化结果，余弦相似度也不是模型判断正确的概率。

证据：[clip_retrieval.json](../results/clip_retrieval.json)记录五条查询的完整结果；[clip-inputs](../results/clip-inputs/)含全部六张输入；[assets/inputs](../assets/inputs/)保留三张原始候选图。

模型为 `openai/clip-vit-base-patch32`，revision：`3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268`。原运行使用CPU；本次迁移保留既有推理结果，没有重下载或重新推理模型。
