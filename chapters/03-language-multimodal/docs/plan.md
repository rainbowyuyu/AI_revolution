# 语言连接万物 · 制作计划

## 具体目标

让模型根据一句话找到对应图片，再理解语言与其他模态如何建立联系。

## 教学推进

1. 从歧义句和图文检索的具体目标进入。
2. 词元、位置、注意力与下一词预测逐层解释。
3. 图文对齐、指令微调与偏好学习分别解决什么问题。
4. 比较准确回应、错误回应与缺失上下文的边界。
