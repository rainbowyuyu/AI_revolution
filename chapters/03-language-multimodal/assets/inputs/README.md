# CLIP 固定候选图

这三张图为本项目生成的场景，用于同一组检索实验，分别是雨后蓝门旁的红伞、街上的红车、草地上的伞。它们与视频实验使用的文件逐字节一致，原始 SHA-256 和迁移记录见 `../../results/migration-manifest.json`。

推理使用的六张实际 224 × 224 图像保存在 `../../results/clip-inputs/`，分别对应默认中心裁剪与先补成正方形的对照条件。它们是模型预处理后的真实输入，不是用于装饰的缩略图。

这些候选用于观察分词以外的跨模态检索、裁剪影响和候选集合的局限；三张图的匹配结果不等同于开放场景的图像识别准确率。材料权利按仓库根目录的 `LICENSE.md` 执行。
