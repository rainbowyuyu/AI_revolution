# 从回答到完成 · 制作计划

## 具体目标

让系统完成一个可验证的小任务：找资料、执行代码、检查产物。

## 教学推进

1. 从一个有输入和验收标准的实际任务开始。
2. 分清增加推理计算、检索和调用工具。
3. 展示可观察的工具输入输出与失败修复。
4. 对比一次回答与带反馈执行的结果和成本。
