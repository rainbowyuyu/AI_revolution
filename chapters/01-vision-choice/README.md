# 第一章 · 看见与选择

**计算机怎样从图片中作出判断，又怎样根据反馈选择行动？**

![第一章看见与选择封面](publication/2026-09-23/covers/第一章_横版16x9_1920x1080.jpg)

给它一张图片，让它作出判断；给它一根快要倒下的杆，让它学会控制；再给它一个棋盘，看看它怎样提前比较落子的后果。三个真实任务串起 **CNN、DQN、MCTS，以及 AlphaGo／AlphaGo Zero 背后的方法**。

## 动手：数据和结果都在这里

在仓库根目录运行以下命令即可先核查已有证据，不需要 GPU 或视频素材：

```powershell
python tools/check_evidence.py
```

想实际训练或运行搜索，打开[完整复现实验指南](docs/复现实验.md)。环境安装、CIFAR-10 下载、三个运行入口、种子与评估口径全部在本章内部。

| 实验 | 本次设置 | 真实记录 |
|---|---|---|
| CNN / CIFAR-10 | 45,000 训练、5,000 验证、10,000 测试；种子 17/42/2026；20 epochs | 准确率 59.42%、60.84%、59.57%；均值 59.94%，样本标准差 0.78 个百分点 |
| DQN / CartPole-v1 | 每种子训练 600 回合；各 100 个独立评估种子 | 平均回报 500.00、490.76、500.00；随机基线 21.15 |
| MCTS / 四子棋 | 每步 64/256/1,024 次搜索；每档 30 组交换先手 | 胜/平/负 59/0/1、60/0/0、60/0/0；对手为随机策略 |

这些结果描述保存的运行。猫狗示例来自十分类模型；CartPole 输入为四个状态数值；四子棋使用随机 rollout，没有复现 AlphaGo 的神经网络或棋力。失败与口径详见[实验结果](docs/实验结果.md)。
