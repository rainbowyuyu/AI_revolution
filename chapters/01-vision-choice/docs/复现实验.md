# 原制作环境复现实验记录

> 当前仓库推荐入口是 [隔离复现指南](../../../docs/REPRODUCIBILITY.md)。以下保留原制作时的配置说明；不要直接运行会复用/覆盖既有结果的训练命令。

从工程根目录执行。Python 3.12，Remotion 4.0.526，PyTorch 2.11.0。完整环境快照见 environment.txt。训练使用独立 .venv312；本机通过 .pth 只读复用已有 TTS 的 PyTorch，不修改原 TTS 环境。迁移到其他电脑时新建虚拟环境并按 PyTorch 官方方式安装适配 GPU 的版本。

```powershell
py -3.12 -m venv .venv312
./.venv312/Scripts/python -m pip install torch numpy pillow pyarrow gymnasium==1.2.3 open_spiel==2.0.2 absl-py ml-collections
./.venv312/Scripts/python scripts/train_cnn.py
./.venv312/Scripts/python scripts/train_dqn.py
./.venv312/Scripts/python scripts/run_search.py
./.venv312/Scripts/python scripts/check_experiments.py
```

三个训练脚本遇到已有 run-种子.json 时复用结果。要独立验证训练，请复制源码、许可证和数据到新的目录并建立 public/experiments、checkpoints、research/experiments 子目录；不要覆盖本片的证据。更改模型或训练配置后不得沿用旧缓存。

CNN：官方小型双卷积结构；SGD lr=0.001、momentum=0.9、batch=64、20 epochs。种子 17、42、2026。划分种子 2026 固定，仅训练部分更新参数，以验证损失选 checkpoint，随后测试。数据采用 uoft-cs/cifar10 的 Parquet 镜像，保留官方 50,000/10,000 划分；具体下载地址和 SHA-256 在 research/experiments/cnn/mirror-provenance.json。本次没有用不完整的原 tar 文件训练。图中卷积响应来自 seed 17 的实际 conv1/ReLU，通道独立 min-max 显示，不能跨通道比较绝对亮度。案例选择为固定首个正确/错误猫狗和最低最大预测概率，非随机抽样。遮挡是归一化后置零，相当于原图中性灰。

DQN：4→128→128→2，AdamW 0.0003，gamma 0.99，batch 128，tau 0.005，replay 10,000，epsilon 0.9→0.01、指数尺度 2500 交互步，600 回合。保留 terminated 与 truncated 的区别，仅真正终止取消未来价值。训练种子 17/42/2026；评估环境种子 900000—900099，无训练随机探索；随机基线独立按同一 seed 初始化动作空间。examples 中的 state 是执行该步 action 之前的状态，reward/结束标志对应随后执行该动作。

MCTS：固定上游 Python mcts.py，C++ 规则由 pyspiel 2.0.2 提供。上游 Python commit 与二进制版本单独记录，不能声称同一源码整体编译。7 列×6 行，预算 64/256/1024，UCT 常数 sqrt(2)，随机 rollout 1 次，solve=False。对手随机种子 3000+pair，搜索种子 8000+pair×2+side。树中 action 为 0-based 列号，画面改为 1-based；根节点统计是最终运行快照，逐渐出现只是展示方式，不声称逐次记录了每次模拟。

目录：public/experiments 是画面读取的数据；research/experiments 保留原始日志、测试概率与棋谱；checkpoints 是训练模型。CPU 与 GPU 的浮点误差可能略有差异，本片使用相同 GPU 路径重载检查概率一致性。
