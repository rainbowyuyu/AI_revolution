## 1. 恢复外部素材

使用仓库 `shared/assets/manifest.json` 中本章记录。在仓库根目录执行：

```powershell
python tools/assets.py status --project chapters/01-vision-choice
python tools/assets.py restore --source-root "<原工程的 video_project 目录>" --project chapters/01-vision-choice
python tools/assets.py status --project chapters/01-vision-choice --verify
```

`source-root` 下应有 `ai_evolution_ch01_vision_choice/`，工具按体积与 SHA-256 恢复授权备份中的素材。已有目标与清单不匹配时保留并报告；新克隆未恢复素材时状态检查返回 1 是预期结果。

默认恢复当前画面、论文页、字体和主音轨，跳过单句语音。要重新混音可添加 `--include-voice-clips`。已退役的旧 master 不属于当前默认恢复范围，不要为运行旧脚本而替换 V9 的声音。详见[共享素材说明](../../../shared/docs/ASSETS.md)。

## 2. 编辑与渲染

使用 Node.js 22 和 npm。在仓库根目录开始：

```powershell
Set-Location chapters/01-vision-choice
npm ci
npm run check
npm run studio
```

Studio 选择 **`ChapterV9-1080`**。以下命令在本章目录运行：

```powershell
npm run stills
npm run render:intro
npm run render
```

| 命令 | 输出 |
|---|---|
| `npm run stills` | `output/current/frame-<帧号>.jpg`，覆盖开场、实验、搜索与论文 |
| `npm run render:intro` | `output/current/第一章_V9_片头90秒_1080p.mp4` |
| `npm run render` | `output/current/第一章_看见与选择_V9_1080p.mp4`，完整带声合成 |

`scripts/render_current.mjs` 直接渲染当前完整 composition 和主音轨，无需历史 patch 拼接链路。`render_v9.mjs`、`render_v8.mjs` 是历史局部或无声渲染辅助，不是当前默认入口。类型检查不依赖完整媒体，实际渲染必须先恢复；长片耗时取决于机器。

## 3. 修改画面或讲稿

1. 先确定实际任务和对应实验记录，保留样本、状态、动作和数据之间的关联。
2. 卷积与池化展示真实响应；概率柱用长度插值，棋盘与搜索树共享同一落子，避免为显得动态而反复淡入淡出数值。
3. 旁白变动后重新测时，同步当前帧区间、字幕和 `anchors`，不能只改变一侧。
4. 检查常驻 Logo、代码、来源和字幕的安全区，再查看接缝两侧主体、曝光和运动方向。
5. 代表片段通过后完整渲染，解码核查与实际观看分别记录。原 QA 报告放在 [evidence/](evidence/)，不代表本次修改已自动通过。
