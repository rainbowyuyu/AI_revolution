## 调整片头或混音

沿用独立的本地 Qwen3-TTS 环境。设置 `RAINBOW_TTS_ROOT` 指向自己的 TTS 模型和声音参考目录；私人声音参考与基础模型不进入本仓库。详细依赖见[共享声音规范](../../../shared/docs/AUDIO.md)。

先在仓库根目录恢复本章单句素材：

```powershell
python tools/assets.py restore --source-root "<原工程的 video_project 目录>" --project chapters/01-vision-choice --include-voice-clips
```

然后在本章目录内，用相应 TTS 环境运行：

```powershell
$env:RAINBOW_TTS_ROOT = "<自己的 TTS 环境目录>"
$env:PYTHONUTF8 = '1'
python scripts/audio_v8.py voice
python scripts/mix_v8.py
```

`audio_v8.py voice` 只生成片头；`mix_v8.py` 使用片头及既有主体记录混音。正文历次修音流程没有作为一键工具导出，改正文时应按对应语音记录重新合成整句、实测并对齐。历史 ASR 检查可能需要原工程额外缓存，缺少缓存不等于现有主音轨损坏。

## 本章重点

- **AlphaGo** 按英文整体读，不替换为“Alpha 围棋”；**ReLU** 作为完整词，不逐个读字母。
- 作者名保持 **rainbow鱼**，中英文衔接自然；行列等多音字逐句复听。
- 显示文本可与 TTS 读音文本分开保存，但最终字幕必须匹配口播内容。
- “窗口移动”“概率变大”“回传到父节点”等讲解均对应实际动作锚点；变更语速后重新定位动作。
- 保留句尾与换气，处理杂音后检查是否引入金属感、延迟或截断。背景音乐随旁白压低，无章节切换提示音。

仓库根目录的 `python tools/export_supplements.py` 负责导出当前字幕和讲稿，不替代语音识别或听审。源文本可在 [supplements/口播.md](../supplements/口播.md) 阅读；字幕切短并检查第二行安全区，避免与代码、来源和 Logo 互相遮挡。
