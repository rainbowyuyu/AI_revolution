## 封面

当前 **4:3 封面更新为 V7，其余三个比例为 V6**。4:3 保留踏雪的近景大小与自然吐舌表情，背景换成青金色噪声逐渐组织成结构的连续波面，精修毛缘与前后遮挡，去掉容易被看成额外尾巴的背景纹理。其他比例继续以“噪声 → 模糊结构 → 清晰毛发图像”的空间变化呼应扩散去噪。

四比例保持原标题、Logo、字号与排版位置，并分别检查主体遮挡和手机缩略图。封面是概念图，不代表本章的小型 GAN/DDPM 实验输出；正片版本仍为 V18。
