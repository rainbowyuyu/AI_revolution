# 第二章静态素材

- `experiments/features-v2/` 与 `experiments/prediction/`：随 Git 保存的 33 张小型实验图。
- `experiments/digits/`：运行 `npm run assets:prepare` 从 `../results/digits/` 恢复的 50 张派生副本。
- `fonts/NOTICE.md`、`fonts/OFL.txt`：两种中文字体的实际版权声明与官方 OFL 1.1 许可正文，随 Git 保存。
- 其他角色、背景视频、音频、论文图、字体与可选帧缓存：外部素材，不随 Git 保存。

完整恢复步骤、素材权限和 V18 入口见 [视频工程说明](../docs/视频工程.md)。精确清单见 [video-manifest.json](../assets/video-manifest.json)。
