# 第二章制作与维护计划

## 已实现的目标

本章围绕“AI 怎么画出真实图像”，以踏雪作为条件生成案例，把分布学习、对抗训练、逐步去噪与图像控制连起来。当前版本为 V18，30 fps、54,724 帧（30:24.133）；公开资料按该版本整理。

## 已完成的内容

- 二维八峰 GAN/DDPM：种子 12、25、2003，每种子每模型 6,000 次更新，保留训练记录、权重、真实采样和指标。
- MNIST GAN/DDPM：种子 42，各 3,000 次更新，保留数字训练/生成过程及 200 步去噪结果。
- 踏雪的身份、动作、条件控制与编辑示例；采用“她”，并与小模型的点/数字实验分开说明。
- GAN、DCGAN、早期扩散、DDPM、DDIM、潜空间扩散和 CFG 七篇论文阅读。
- 59 段可编辑时间线、315 句讲稿、524 条字幕、V18 素材恢复清单、封面及发布文案。

完整路线见[图文讲义](图文讲义.md)和[时间导航](../supplements/章节时间索引.md)。实际结果与检查见[实验结果](实验结果.md)，不再沿用原占位计划中的“实验未执行”状态。

## 后续修改顺序

1. 先确定修改影响讲稿、实验结果、动画还是素材；保留本次发布的实验原件与哈希。
2. 新实验写独立 `runs/`，审核后再导入；不要覆盖当前 `results/` 来制造相同结果。
3. 旁白变更同步修改字幕、逐句锚点和场景时长；当前 V18 复用 V16 字幕与 V15 画面时钟。
4. 视频素材变化更新 `assets/video-manifest.json`；论文页面按真实 PDF 定位，保留来源。
5. 运行源码、证据与素材检查，再审看受影响片段及接缝。先完整 1080p 预览，确认后交付对应 4K。
6. 更新 `chapter.json`、根 `series.json`、本章入口、字幕和发布文案，使所有入口指向同一版本。

参见[视频工程](视频工程.md)及[跨章维护流程](../../../docs/MAINTENANCE.md)。
