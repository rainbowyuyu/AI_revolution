# 从识别到创造 · 制作计划

## 具体目标

把一团噪声逐步变成可以辨认的图像，理解模型为什么能创造新内容。

## 教学推进

1. 从真实图像与生成样本的对照提出问题。
2. 用二维分布展示 GAN 的生成与判别反馈。
3. 让同一个样本逐步加噪与去噪，对齐每一步的真实中间结果。
4. 比较条件控制与失败样本，不把生成画面冒充训练测量。
