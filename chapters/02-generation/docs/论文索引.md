## 建议阅读顺序

1. 先读 GAN 的 Algorithm 1，辨认哪一步更新判别器、哪一步更新生成器，再对照 [讲义中的两个损失](图文讲义.md)。
2. 把 DDPM 的 Algorithm 1 与 Algorithm 2 并排看：前者用已知噪声更新参数，后者固定参数并更新样本。这是理解“学会去噪”和“开始生成”的关键。
3. 带着计算成本问题看 DCGAN、DDIM 和潜空间扩散，分别辨认网络结构、采样过程、工作空间发生了什么变化。
4. 最后读 CFG，先对齐论文与软件对引导系数的定义，再讨论条件强度对结果的影响。

这些论文支持本章的机制解释和历史脉络。本仓库的二维/MNIST 实验是独立的小型教学实现，数据、网络规模和训练预算与原论文不同，不能视为论文的大规模性能复现。实验结论入口为 [实验结果](实验结果.md)。
