# 第二章实验复现

本章提供两个实际运行过的教学实验：二维八峰分布上的 GAN/DDPM，以及 MNIST 手写数字上的小型 GAN/DDPM。原始结果、采样过程和八个小模型权重随仓库保存，可以先检查结果，再决定是否重新训练。

以下命令均从仓库根目录执行。新的训练只写入指定的空运行目录；随片历史结果位于 [`results/`](../results/)，不会被正常复现命令覆盖。

## 安装

推荐 Python 3.12 和独立环境：

```powershell
py -3.12 -m venv .venv-ch02
.\.venv-ch02\Scripts\Activate.ps1
python -m pip install -r chapters/02-generation/requirements-experiments.txt
python -c "import torch,numpy,PIL; print(torch.__version__, torch.cuda.is_available())"
```

按 [PyTorch 安装说明](https://pytorch.org/get-started/locally/)选择适合机器的 CPU/CUDA wheel。实验最小依赖只有 PyTorch、NumPy 和 Pillow，数据下载使用 Python 标准库。原始 JSON 记录了 `torch=2.11.0+cu128`；本次整理验证环境为 Python 3.12.10、PyTorch 2.11.0+cu128、NumPy 2.5.3、Pillow 12.3.0。这些核查版本不等于完整的历史环境锁定文件。

## 先做短运行

```powershell
python chapters/02-generation/experiments/train_distributions_v5.py --smoke --device cpu --run-dir runs/ch02-dist-smoke
python chapters/02-generation/experiments/train_digits.py --smoke --device cpu --run-dir runs/ch02-digits-smoke
```

两条命令都支持 `--device cuda`；数字实验默认 `auto`，自动选择可用 CUDA，否则使用 CPU。二维实验默认 CPU，与历史执行路径一致。

二维 smoke 只训练第一个种子的 GAN、DDPM，各 10 步，保留 200 步采样与 2,048 个评估点。数字 smoke 使用实际 MNIST 训练数据的前 256 张、验证部分的前 32 张，各训练 2 步，生成 4 张图；GAN/DDPM batch 分别缩为 16/8，仍完成 200 步反向采样。短运行只验证执行流程，其结果不用于比较模型质量。

数字实验首次运行会从 CVDF 镜像下载约 9.9 MB 的官方训练图像 gzip 文件，保存到 `runs/datasets/mnist/`。下载和缓存每次均核对 SHA-256：

```text
440fcabf73cc546fa21475e81ea370265605f56be210a4024d2ca8f203523609
```

已有该文件时可传 `--data-dir 你的数据目录`。文件名须为 `train-images-idx3-ubyte.gz`。实验不下载标签，也不使用官方测试集。

## A. 二维八峰分布

```powershell
python chapters/02-generation/experiments/train_distributions_v5.py --steps 6000 --seeds 12 25 2003 --device cpu --run-dir runs/ch02-distributions-001
```

目标是在半径 2 的圆上等角放置 8 个二维高斯分布，每个坐标的标准差为 0.12，训练批次现场独立采样。

| 项目 | GAN | DDPM |
|---|---|---|
| 模型 | 生成器 2→128→128→2，判别器 2→128→128→1；SiLU | 2 个空间坐标 + 16 维时间编码→128→128→2；SiLU |
| 更新次数 | 6,000 | 6,000 |
| Batch | 256 | 512 |
| 优化器 | Adam，lr=0.0002，betas=(0.5,0.999) | Adam，lr=0.001，默认 betas |
| 损失 | 判别器二元交叉熵；生成器非饱和目标 | 预测噪声的均方误差 |
| 采样 | 高斯潜变量，经生成器一次前向 | 200 个时间步的 DDPM 祖先采样 |
| 噪声日程 | — | β 从 0.0001 线性增至 0.05 |

每个模型以对应训练种子重新初始化；评估种子为 `训练种子+10000`，生成 2,048 个点。距离最近中心小于 0.36 的样本计为“近邻”；某个中心至少收到 10 个近邻样本才算覆盖。覆盖 8/8 仍可能有大量点落在区域之外，应同时看近邻比例和平均距离。

DDPM 验证另用独立种子 91234 生成 4,096 个干净点、噪声和时间步，报告噪声预测 MSE。GAN 保存 41 个训练快照、固定端点的 61 个插值点；DDPM 保存初始噪声及每 4 个反向时间步的轨迹。结果 JSON 中坐标保留 5 位小数，指标由舍入前张量计算。

## B. 手写数字

```powershell
python chapters/02-generation/experiments/train_digits.py --steps 3000 --seed 42 --device cuda --run-dir runs/ch02-digits-001
```

没有 CUDA 时将 `cuda` 换成 `cpu`。原始执行设备是 CUDA，CPU 全量训练会较慢。

MNIST 官方训练图像按文件原顺序划分：前 55,000 张用于训练，后 5,000 张作为验证部分；输入为 28×28 灰度图，缩放到 [-1,1]。原脚本仅在生成最终样本后，用验证部分的前 512 张和随机时间步/噪声计算一次验证 MSE，没有遍历全部 5,000 张。

| 项目 | GAN | DDPM |
|---|---|---|
| 模型 | 生成器 64→256→512→784，末层 Tanh；判别器 784→256→128→1；LeakyReLU(0.2) | TinyUNet，24/48 通道、GroupNorm、SiLU，平均池化下采样、最近邻上采样和跳接 |
| 输入条件 | 64 维高斯潜变量 | 加噪图像 + 2 个时间平面；没有数字标签条件 |
| 更新次数 | 3,000 | 3,000 |
| Batch | 128 | 64 |
| 优化器 | Adam，lr=0.0002，betas=(0.5,0.999) | Adam，lr=0.0005，默认 betas |
| 噪声日程 | — | 200 步，β 从 0.0001 线性增至 0.04 |
| 保存样本 | 固定 32 个潜变量，8 个训练阶段 | 32 张图，初始噪声及每 5 个反向时间步 |

训练入口先设置 seed 42，先训 GAN，再沿同一随机状态继续初始化并训练 DDPM；不是为两个数字模型各自重新设置一次 42。DDPM 生成阶段重新设置 seed 10042。两类实验的种子体系独立，不能把二维的 12/25/2003 套到数字实验。

## 复核已保存证据

只检查文件和数据，无需实验依赖：

```powershell
python chapters/02-generation/experiments/check_evidence.py
```

该检查核对 63 项原始产物的 SHA-256、两份历史源码哈希、六组 2,048 点的统计、训练记录、摘要与轨迹一致性。文件清单见 [`artifact-manifest.json`](../results/artifact-manifest.json)。

需要 PyTorch 的深度检查：

```powershell
python chapters/02-generation/experiments/check_evidence.py --deep --device cpu --report runs/ch02-check-cpu.json
python chapters/02-generation/experiments/check_evidence.py --deep --device cuda --report runs/ch02-check-cuda.json
```

深度检查以 `weights_only=True` 读取八个 checkpoint，在 CPU 上重新生成全部六组二维样本；MNIST 重新执行生成器/判别器推理以及 32 张图的完整 200 步 DDPM 采样。CUDA 路径还与历史数字终图逐像素比对（允许最大 1 灰度级）；CPU 和 CUDA 随机流不同，CPU 路径只验证推理与有限数值，不要求历史图像相同。数字验证 MSE 的历史记录不在此核查中重新计算。

本次深度检查记录见 [`verification-2026-09-29.json`](../results/verification-2026-09-29.json)。六组二维样本最大误差约 5.13×10⁻⁶，符合 JSON 的 5 位小数舍入；CUDA 数字终图最大像素差为 0。该报告证明本次检查，不代表将来每台机器都会得到完全相同的浮点值。

## 原始记录与便携入口

[`experiments/original/`](../experiments/original/) 保留两份历史源码原字节，用于匹配原 JSON 中的 `code_sha256`，不建议直接执行它们。上面的入口在原算法基础上增加了输出隔离、设备选项、短运行和数据哈希校验，移除了制作工具与 `requests` 依赖，并补充本次执行环境信息。

新运行的目录必须为空，重复使用会被拒绝。checkpoint 保存模型权重及部分配置，没有优化器状态，不能据此承诺逐步完全一致的断点续训。重训结果属于新实验，需自行核对，不能用它静默替换本仓库的历史数字。

这些网络用于理解分布学习与图像去噪。踏雪角色图像和视频是另一条创作流程，角色参考、外部生成工具和视觉检查见[图像生成与角色示例](图像生成与角色示例.md)。本实验没有训练写实踏雪生成器。
