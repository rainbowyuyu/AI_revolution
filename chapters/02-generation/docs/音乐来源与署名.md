# 第二章 V18 音乐来源与署名

本章使用 **Bleeping Demo — Kevin MacLeod**，以同一首柔和电子音乐贯穿全片。配乐做轻节奏、疏节奏、温暖氛围和轻微推进四种层次变化，保留原曲音高与 74 BPM，通过长渐变连接，并在旁白出现时降低音乐音量。
